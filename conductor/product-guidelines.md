# Product Guidelines - newApp

## Voice and Tone

**Professional and technical.** UI copy and documentation use polished, precise
language suited to a technically literate audience. Avoid slang and excessive
exclamation; favor clarity and accuracy.

## Design Principles

1. **Simplicity over features** — keep the UI and feature set minimal and focused on reading stories.
2. **Performance first** — prioritize fast load times and responsive interactions.
3. **Reliability** — gracefully handle Hacker News API failures and degraded states; never show a blank or broken screen.
4. **Accessibility** — ensure the UI is usable with keyboard navigation and screen readers (semantic markup, alt text, focus states).

## Application

These principles apply to every track. When trade-offs arise, prefer the simpler,
more reliable option over additional features, and never ship UI that regresses
performance or accessibility.
