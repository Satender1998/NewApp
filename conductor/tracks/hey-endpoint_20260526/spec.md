# Specification: "hey satender" Greeting Endpoint

**Track ID:** hey-endpoint_20260526
**Type:** Feature
**Created:** 2026-05-26
**Status:** Draft

## Summary

Add a small backend API endpoint, `GET /api/hey`, that returns the plain-text
response `hey satender`.

## Context

newApp is a stateless Express backend (`api/index.js`) that proxies the Hacker
News API and serves the built React client. It already exposes simple endpoints
such as `GET /api/welcome`. This track adds another lightweight endpoint in the
same style, supporting the goal of keeping the codebase small and easy to extend.

## User Story

As a developer/consumer of the newApp API, I want a `GET /api/hey` endpoint that
returns `hey satender`, so that I have a simple greeting endpoint to call.

## Acceptance Criteria

- [ ] `GET /api/hey` responds with HTTP 200.
- [ ] The response body is the plain text `hey satender` (not JSON).
- [ ] The endpoint is registered before the static-file/catch-all routes so it is
      reachable.
- [ ] Existing endpoints and the backend test suite remain unaffected.

## Dependencies

None. Uses the existing Express app in `api/index.js`.

## Out of Scope

- No frontend/client changes.
- No authentication, parameters, or dynamic/personalized greetings.
- No JSON response shape (plain text only, per decision).

## Technical Notes

- Follow the existing `lib/` module pattern (`upstreamError.js`): extract a small
  `heyHandler(req, res)` into `api/lib/hey.js`, returning `res.send("hey satender")`.
- Wire it into `api/index.js` as `app.get("/api/hey", heyHandler)`, placed with the
  other `/api/*` routes (before the static + `*` catch-all handlers).
- Add `api/lib/hey.test.js` using `node:test` with a fake `res` object, mirroring
  `upstreamError.test.js`.
